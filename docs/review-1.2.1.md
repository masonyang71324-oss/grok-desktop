# 1.2.1 发布前复查

本文记录发布前的本机检查。后续已创建[公开仓库](https://github.com/masonyang71324-oss/grok-desktop)并启用私密漏洞报告；托管检查结果见 [GitHub Actions](https://github.com/masonyang71324-oss/grok-desktop/actions)。

在当前 Windows 范围内，已修复本轮发现的两个功能缺陷，未发现其他有证据的发布阻塞。建议先公开为 Windows 预发布版本，收集不同机器上的安装和使用反馈。

## 已修复

| 问题                   | 原行为                                                              | 1.2.1 行为                                                               |
| ---------------------- | ------------------------------------------------------------------- | ------------------------------------------------------------------------ |
| 未保存文件退出丢失     | 空闲时编辑文件，直接关闭整个应用会静默丢失修改                      | 关闭或重新载入前确认；取消后保留编辑和正在运行的任务；保存后正常退出     |
| 界面恢复后失去任务控制 | 等待批准时重新载入，原 ACP 回合仍在等待，但新界面没有批准和停止按钮 | 确认恢复时先中断原连接并结算待批请求，再载入历史；可继续发送和批准新请求 |
| 历史文档歧义           | 1.1.0 的“仅中文”状态可能被误认为当前状态                            | 明确标注历史版本，并指向当前版本记录                                     |

两个功能问题均先在隔离 Electron 环境复现，再加入回归测试。恢复窗口明确说明会中断当前任务。
