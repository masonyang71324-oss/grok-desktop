# 1.5.1 最终复查

复查基线为 1.5.0（925d157），范围包括任务/队列/恢复、首页统计和模型选择、附件与文件读写、更新和发布链路。发现以下五项可复现问题，补丁仅处理这些问题。

| 问题                                             | 修复                                                       |
| ------------------------------------------------ | ---------------------------------------------------------- |
| 准备附件或模型配置期间停止，仍可能发出提示词     | 发送前读取取消状态，停止后不创建模型回合，排队消息保持暂停 |
| 前台回复结束就通知完成，后台工作或检查点尚未结束 | 在整轮任务完成后通知，区分完成、停止、失败/中断            |
| `[id].tsx` 等路径被 Git 当成模式匹配             | diff 和 tracked-file 查询均使用字面路径                    |
| GBK 文件被替换字符解码后允许覆盖保存             | 拒绝有损读取，提示外部打开；UTF-8 BOM 和截断预览保持正确   |
| 新项目的默认推理显示继承上一会话实际档位         | 未选会话时根据保存偏好和模型公布的默认值显示               |

附件提取的 GBK/GB18030 支持保持不变。内置编辑器暂只编辑 UTF-8 文本；此限制保护原文件，不自动转换编码。

## 性能与后续方向

本机 Chromium 153 基准（`npm run bench:markdown`，每项 5 次预热、15 次更新取中位数）：10,000 字符 7.0 ms，30,000 字符 20.1 ms，60,000 字符 39.6 ms。该数字是 React 更新及布局耗时，不代表模型响应速度。超长回复可进一步优化解析范围，但需要保留跨段引用链接的正确性。

后续可独立考虑：长回复渲染优化、更多文本编码的原样编辑、发布者签名。当前没有为了追版本合并 TypeScript/Vite 等大版本升级。

模型可用性、额度和上下文数据以官方账号接口为准。自动测试使用隔离的模拟 Grok；不代替真实付费模型服务、所有网络条件或不同电脑的验证。
