# Grok Desktop 1.6.0

按选定的第三版设计整理桌面布局，简化视觉层级，保留全部现有功能。

- 左侧整合“会话 / 文件 / 任务”，切换不丢失草稿和文件编辑内容。
- 底部集中显示连接、套餐额度、上下文和 Desktop / Build 版本，保留两个软件各自的更新入口。
- 聊天与输入区统一比例、字号、间距和对齐，减少多余边框；小窗口可继续使用发送、权限和队列操作。
- 推理设置合并为一个菜单，保留快速、标准、深入预设以及模型公布的全部精确档位和默认值。
- 文件差异、计划、审批、队列、停止、检查点恢复、项目脚本、提示词收藏、管理动作和中英双语均保留。
- 修正嵌入编辑器的弹窗层级、菜单关闭后的焦点，以及收起侧栏后的文件入口行为。

350 项自动测试、类型检查、生产构建和完整源码 Electron 流程通过。设计预览使用模拟会话，不代表模型的实际执行结果。Windows 安装包仍未配置发布者签名。
