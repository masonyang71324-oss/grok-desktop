# Grok Build Desktop 1.11.0

本版完整应用已确认的品牌与界面设计，保留原有会话、草稿、项目能力与推理滑轨。

- 使用已选的方形 G 标志，更新应用内、Windows 图标、窗口标题与快捷方式显示名为 **Grok Build Desktop**。
- 统一深石墨与冷翡翠绿界面；左侧项目/会话导航、跨栏顶栏、对话区、输入工具与底部状态栏采用同一套间距与配色，保留浅色主题和中英文。
- 宽屏增加可折叠、可调宽度的右侧项目上下文，与左侧会话/任务同时使用；窄屏回到左侧面板。单个 Inspector 实例在两侧移动，未保存的文件编辑不会因缩放窗口丢失。
- 右侧直接预览文件差异，仍可打开完整差异、切换并排查看与添加到上下文。
- 输入区按附件/引用/语音/动作和模型/推理/上下文/模式分组；保留权限、队列、停止、恢复和更新入口。

安装标识、原数据目录、可执行文件名及更新包命名保持兼容。新显示名不会创建一份空白历史目录。

## English

- Apply the approved square G mark and Grok Build Desktop branding throughout the app, Windows icon, window title and shortcuts.
- Unify dark graphite/emerald styling, navigation, the spanning toolbar, conversation, grouped composer and persistent status strip; preserve light mode and both languages.
- Add an independent collapsible right context pane on wider windows, with a left-pane fallback on smaller windows. Keep one persistent Inspector so unsaved edits survive docking and resizing.
- Preview diffs inline while retaining full, side-by-side and add-to-context actions.
- Preserve every existing capability, permission, queue, stop/recovery and update entry point, and retain installation/data identity for in-place upgrades.
