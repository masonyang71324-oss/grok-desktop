# Grok Desktop 1.0.4 复查记录

本轮围绕实际使用中的内容丢失、恢复失败、操作准确性和长回复性能检查，发现并修复以下问题。

| 问题                           | 可复现的触发方式                                                             | 本次处理                                                                                               |
| ------------------------------ | ---------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| 会话草稿丢失或无法找回         | 先输入再选择项目；输入后切换会话或重启；官方历史列表省略从未发送过消息的会话 | 保存无项目草稿及各项目、会话的正文与附件；选项目时保留已有输入，侧栏保留有草稿的会话，启动恢复上次选择 |
| 显示已连接却不能继续原会话     | Grok 进程退出后，后台只读查询重新建立连接，但原会话未重新载入                | 恢复会话后才显示就绪；合并重复恢复请求，保留恢复期间输入                                               |
| 发送失败覆盖新输入             | 等待发送预检期间继续编辑，随后预检失败                                       | 保留新输入，移除实际未发送的临时消息；成功时只清理已提交的那份草稿                                     |
| 文件保存覆盖新输入             | 点击保存后继续编辑，保存结果稍后返回                                         | 更新已保存基线和时间戳，保留后来编辑；旧项目的异步结果不再污染当前项目                                 |
| Git 子目录项目差异报错         | 把仓库内子目录作为项目，打开变更文件                                         | 统一项目相对路径；正确处理暂存、未暂存、未跟踪及跨目录移动                                             |
| 中文输入法误触发               | 用 Enter 确认或 Esc 取消候选词                                               | 重命名及弹窗快捷键识别组合输入状态                                                                     |
| 流式回复干扰阅读并增加渲染开销 | 横向滚动已完成代码块，再收到回复追加内容                                     | 保留未改变的 Markdown 节点、滚动位置和选中文本，仅替换变化内容                                         |
| 无效的管理选项                 | MCP 启停或插件安装选择“作用范围”                                             | 移除官方 CLI 不支持、实际不会生效的范围选择；添加/移除 MCP 的有效范围保留                              |

## 性能证据

对同一台电脑、同一页面的合成长回复进行追加更新对照：3 万字符中位耗时从 69.6 ms 降至 25.3 ms，6 万字符从 97.9 ms 降至 41.0 ms。此结果描述桌面渲染开销，不代表 Grok 模型生成速度。

继续沿用完整 Markdown 解析与 DOMPurify 净化，因此后续出现的引用定义仍可更新前文；已验证列表、表格、文本缩短、清空和链接行为。

## 验证与边界

74 项自动检查全部通过，TypeScript 与生产构建通过。最终 1.0.4 打包程序通过首次选择项目前输入的保存与重启、各会话草稿切换与重启、文件保存期间继续编辑、中文输入法候选操作和实际 Grok 进程重连恢复；中文批准按钮及当前对话权限切换也通过回归，小窗口中的操作按钮保持可见。

安装版、免安装版已生成，桌面快捷方式和项目启动脚本已更新。退出旧版本后，重新打开桌面上的 Grok Desktop 即可。

检查使用专用临时项目、合成回复和独立应用数据目录。文件保存缺陷在真实 Electron 程序中先复现再修复。Git 路径使用真实隔离仓库验证。没有执行用户截图中的命令。

面向正式销售，仍需配置发布者代码签名、桌面应用的自动更新渠道，并进行持续使用和更大项目的稳定性验证。
