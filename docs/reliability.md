# Reliability requirements

这些约束服务于“稳定、简单、功能不削减”。修改涉及某类行为时，沿用其现有保护并验证对应场景；不要求无关改动重复审计全部功能，不为尚未实现的功能提前增加框架。

## 文件和数据

- 截断预览只能查看，不能把前缀或裁剪的行列整体写回原文件。显示用数据与可写的完整数据必须区分。
- 不支持的文本编码必须明确拒绝或正确保留，不能把替换字符写回；合法UTF-8中的替换字符也不能一概视为二进制。
- 保存前校验外部修改；保存失败保留原文件、草稿及dirty状态。保存进行中关闭编辑器，必须保留最后输入和退出保护。
- 检查点恢复先检查全部选中文件冲突；部分I/O失败保留实际已恢复内容的撤销记录；未记录文件不能伪装成可恢复。

实现与回归：`electron/workspace.cjs`、`electron/checkpoints.cjs`、`src/Inspector.tsx`；`tests/workspace.test.cjs`、`tests/checkpoints.test.cjs`、`tests/inspector.test.cjs`、`tests/e2e-lifecycle.cjs`。

## 会话、发送和取消

- 提交时固定session、cwd、文字与附件快照；切换界面不改变在途任务归属。
- 发送准备、附件转换、模型配置阶段也要响应停止。取消一会话不能影响其他会话；重复取消/迟到回调不能重复结算或结束新回合。
- 失败保留完整草稿和附件，不能恢复旧快照而覆盖用户后续输入。
- 取消/失败暂停排队；重启后的中断与队列必须由用户明确继续。后台任务与检查点整理结束前，不释放目录锁或通知整轮完成。

实现与回归：`electron/acp.cjs`、`electron/session-hub.cjs`、`src/App.tsx`；`tests/acp.test.cjs`、`tests/session-hub.test.cjs`、`tests/app-state.test.cjs`、`tests/e2e-recovery.cjs`、`tests/e2e-workflows.cjs`。

## 状态、权限和平台

- 取消、失败、未知、过期数据须准确表达；不能仅凭IPC返回就显示“已完成”。各动作的成功语义单独判断，例如“停止子代理成功”的cancelled字段与“用户取消创建工作树”含义不同。
- 登录按官方CLI实际响应判断；额度和上下文缺失不能填0或100%。检查更新必须真正发出请求，安装成功还要核实目标版本。
- 权限选项表示如何处理Grok发出的批准请求，不冒充操作系统沙箱。运行中改变后续权限，不替代当前待批决定。
- Windows使用平台路径分隔、用户目录和明确项目cwd。中文输入法确认候选不能触发发送；流式UTF-8按完整字符解码，包括错误诊断。
- 日志只写允许的运行元数据，不写正文、附件、工具参数、凭据或完整上游错误。

实现与回归：`electron/cli-status.cjs`、`electron/updater.cjs`、`electron/process.cjs`、`electron/project-runner.cjs`、`electron/logger.cjs`；`tests/cli-status.test.cjs`、`tests/updater.test.cjs`、`tests/management-components.test.cjs`、`tests/desktop-services.test.cjs`、`tests/rendering.test.cjs`及完整Electron流程。

## 尚未引入能力的准入条件

- Office编辑、逐段差异写回：先证明持有完整数据和基线，处理外部修改；只读预览不得暗中升级为编辑。
- 首次CLI安装器：真实进度、超时和取消均覆盖安装进程树；检测到实际可执行版本才算成功。当前应用尚无界面内首次CLI安装向导，不能当成已验收。
- 额外认证/模型来源：退出使在途刷新失效，密钥不进入渲染器或日志；配置刷新保留用户选择。
- 内嵌网页/Office渲染：保留脚本语义、隔离来源、统一外链处理；不得把浏览器界面称为已验证网页结果。
- 宿主FS/terminal ACP：完整实现声明的line/limit/cwd与生命周期，否则不声明支持。现有客户端把这些工具执行留给官方CLI。
- 空闲回收/虚拟列表/Worker：测量收益，保留会话归属、选择复制、滚动位置、附件和后台状态；不能只按“当前未输出”判定任务空闲。

## 1.6.1 对照复查

本轮修复：保存中关闭编辑器可能漏掉后续编辑保护；取消工作树目标选择误报完成；ACP stderr跨块中文乱码。另补截断预览只读与零保存请求的组件回归。

其他已覆盖分支通过源码与既有测试对应核查，并执行会话快照、重复取消、迟到失败保留新输入等隔离探针。尚未引入的功能按上述准入条件处理，不制造无用开关或测试桩。

验证：354项单元/组件测试通过，格式检查、生产构建、源码与打包后的完整Electron端到端流程通过，NSIS与便携包构建成功。首轮测试有一次Windows临时目录EBUSY清理失败，对应单项与全套复跑均通过；没有据此修改产品逻辑，系统占用原因尚未确定。

本机Windows / Node 22.22.2的实际进程探针确认：后代就绪并持续运行后，dispose与实际12秒取消超时均使代理及后代退出；协作取消保留代理连接、仅结算一次。未复现进程遗留，不增加额外终止框架，也不把结果外推到其他Electron或平台版本。

这些是可验证的发布约束，不是对全部环境和未来变更的无故障保证。
