# Grok Build Desktop 1.11.1

- 主界面右上角新增主题选择：深色、浅色、跟随系统。选择后自动保存，重启后保留，收起侧栏也能直接切换。
- 白色主题改为中性白和灰色层级，保留绿色品牌与推理动效；补齐浅色差异高亮、危险按钮及终端对比。
- 终端跟随主题实时变色，不重新启动已有终端进程或清空输出。
- 保存失败时保持原主题并提示；完成保存后恢复键盘焦点，用户已转去输入任务时不抢焦点。

## English

- Add a main-toolbar appearance selector for Dark, Light and System. Choices save automatically and survive restart, including when the sidebar is hidden.
- Use a neutral white/light-gray theme with the same green identity and effort animation, and improve light diff, danger-button and terminal contrast.
- Update the existing terminal's colors without restarting its process or clearing output.
- Keep the previous theme on save failure and preserve appropriate keyboard focus.
