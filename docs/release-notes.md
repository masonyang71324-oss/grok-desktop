# Grok Desktop 1.2.1

1.2.1 修复发布前复查发现的退出保护和界面恢复问题，保留中英双语、权限控制、额度查询和草稿恢复。

## 安装与启动

- 安装版：Grok-Desktop-1.2.1-Setup.exe。
- 免安装版：Grok-Desktop-1.2.1-Windows.exe，首次解压启动较慢。
- 需要已安装并登录官方 [Grok Build](https://docs.x.ai/build/overview)。设置页可浏览选择 grok.exe；自动查找使用 Grok 主目录、用户目录、本地应用目录和 PATH。

## 切换语言 / Change language

1. 打开左下角“设置”，或按 Ctrl + ,。
2. 在“界面语言”选择“简体中文”或“English”。立即保存，无需重启。
3. 英文界面中，通过 Settings → Language → 简体中文 切回中文。

Open **Settings → Language** and choose **English** or **简体中文**. The change applies immediately and is remembered after restart.

界面按钮、动作库、管理表单、额度与上下文、审批选项、系统菜单和通知跟随语言。日期和数字采用对应语言格式。聊天正文、代码、文件名与内容、官方命令和参数保持原样；切换时保留草稿、代码选区和未保存的编辑内容。

## 本次修复

- 文件有未保存修改时，关闭应用或重新载入会先确认；取消退出可继续编辑，运行中的任务也不会先被中断。
- 界面异常后选择“重新连接并载入”，会明确中断当前任务、清理待批准操作，再从历史恢复，避免任务仍在运行但批准和停止按钮已消失。
- 历史审阅文档明确版本，避免把 1.1.0 的功能状态误认为当前版本。

## 开发与验证

运行 npm test 检查单元与组件；npm run build 检查类型并生产构建；npm run test:e2e 使用假 Grok 验证真实 Electron 主进程、preload 与界面，不需要账号。设置 GROK_DESKTOP_TEST_EXE 后，同一 E2E 可检查打包程序。

双语组件测试覆盖切换即时生效、保存失败恢复选择、未保存设置与编辑保留、原始工具内容和协议 ID 不变。Electron E2E 同时检查重启恢复及切回中文。

1.2.1 交付验证：干净源码副本安装与构建通过；114 项自动测试、23 项源码端到端流程和同样 23 项最终打包程序端到端流程全部通过。新增退出与恢复回归的范围见 [发布前复查](review-1.2.1.md)。

性能可以通过 npm run bench:markdown 复现，计时包括同步 React 渲染与布局，使用五次预热和十五次测量；结果不代表模型生成速度。

此前建议的处理状态参见 [1.1.0 历史审阅处理结果](review-response-1.1.0.md)，开发入口见 [README](../README.md)。

## 当前限制

同一时间仍运行一个前台会话。多会话并发、完整编辑器和历史虚拟化留待独立实现。当前发布 Windows 版本，应用为非官方项目；签名身份、桌面更新源和源代码许可证尚待所有者确定。“检查 Grok Build 更新”只更新官方 CLI。
