# Grok Desktop 1.4.2

首页顶部现在常驻显示 Grok Desktop 当前版本和更新状态。点击版本状态即可重新检查；发现新版、正在下载或已经下载完成时，会进入现有的软件更新控制。窄窗口仍保留清晰的版本入口，中英文界面同步支持。

安装版可从 1.4.1 在应用内下载本次更新并选择何时重启安装。便携版会打开公开下载页。Windows 安装包尚未配置发布者签名，可能显示 SmartScreen 提示。

## English

The main toolbar now keeps the installed Grok Desktop version and update status visible. Click it to check again; available, downloading, and ready states lead to the existing software update controls. The entry remains compact in narrower windows and is fully localized in Chinese and English.

Installed 1.4.1 editions can download this update in the app and choose when to restart. Portable editions open the public release page. The Windows binaries are currently unsigned and may trigger a SmartScreen warning.
