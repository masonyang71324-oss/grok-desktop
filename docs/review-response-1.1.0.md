# 1.1.0 审阅处理结果

本页保留 1.1.0 的历史处理状态与验证记录。1.2.0 已加入中英双语界面；当前功能请参见 [版本记录](../CHANGELOG.md) 和 [架构说明](architecture.md)。

本轮同时核对缺陷报告与 25 项改进建议。优先落实可确认的缺陷、日常交互和可复现验证；没有把每个建议都视作可以直接替换的实现方案。

## 已确认的缺陷

- **Windows 换行**：编辑内容统一为 LF 比较，保存时恢复读取到的 CRLF/LF，避免改一个字导致全文件变化。
- **文件保存**：改为同目录临时文件完整写入后替换；失败保留原文件并清理临时文件，保留权限位与外部修改检测。
- **Git 缺失**：保留 ENOENT 错误代码，展示 Git 不可用状态，其他错误仍按错误处理。
- **客户端版本**：ACP 初始化使用桌面实际版本，移除 1.0.0 硬编码。
- **历史加载**：session/load 的等待延长到 120 秒。没有采用“超时后继续复用不确定连接”：如果不知道后台已切换到哪个会话，继续发送会有会话混淆风险。
- **审批误点**：点击遮罩不再取消；保留明确按钮与键盘操作。
- **路径与开发环境**：移除个人盘符探测，改为 GROK_HOME、用户目录、本地应用目录和 PATH；加入程序选择器。官方 npm 包会初始化同一 Grok 主目录里的原生程序，不能简单用 shell:false 启动 .cmd。
- **维护性**：统一 Prettier，打开 TypeScript 未使用符号检查，删除无用导入和未调用接口；esbuild 直接声明，浏览器测试默认使用 Playwright Chromium。

## 判断依据与边界

[官方 ACP 路由](https://github.com/xai-org/grok-build/blob/main/crates/codegen/xai-grok-shell/src/agent/mvp_agent/acp_agent.rs)及[每会话执行代码](https://github.com/xai-org/grok-build/blob/main/crates/codegen/xai-grok-shell/src/session/acp_session_impl/spawn.rs)说明多会话具备上游基础。桌面仍有单例 activeTurn、activeSessionId、恢复与管理互斥；并发版本须一起改造这些状态，不能只去掉锁。

本轮没有增加“只允许本次文件对话框选过的附件”规则，因为已有草稿要跨重启继续使用；也没有禁止项目符号链接的通用规则。当前范围仍是本机操作者明确选择的项目与文件，现有网页隔离与路径边界继续保留。

公开文档已改为独立项目语境；旧的实施说明入口指向当前架构和版本记录。未设置虚构的仓库网址、作者身份或开源许可证，现有安装标识保持稳定。
