# Grok Desktop 1.3.0

本次升级围绕“稳定、容易使用”，继续提供简体中文和 English。

## 新增功能

- **任务中心**：切换会话时任务继续运行；不同项目可并行，同项目自动排队；出错或中断后由用户确认继续。
- **文件检查点**：查看每轮前后变化，选择恢复文件、撤销恢复或删除旧记录；已有后续修改时拒绝覆盖。
- **上下文选择**：将文件、选中代码、Git 差异加入输入区，发送前可以查看内容。
- **项目运行**：自动发现 npm 脚本，点击运行、停止、重新运行、打开本地预览，直接查看日志。
- **截图附件**：支持粘贴和预览图片，按 CLI 能力发送原生图片内容。
- **故障恢复**：提示登录、额度、连接或程序路径问题，保留草稿；界面重载接回原任务和待批准操作。

## 维护与验证

- 更新 DOMPurify 3.4.15、marked 18.0.12；更新 GitHub Actions，合并关联依赖的更新建议。保留现有 Node/TypeScript/Vite 主版本。
- 修复 Electron 44 剪贴板接口适配、准备失败重复排队、工具状态重复、后台任务目录锁、工作流控制和退出检查点收尾问题。
- 155 项测试通过，生产构建、格式检查通过；统一 Windows 短路径和目录别名，确保检查点及项目任务指向同一目录。
- 源码和打包程序均通过四组真实 Electron 流程测试：基础功能、退出保护、重载恢复、完整工作流；测试使用隔离的模拟 Grok，不消耗账号额度。
- 生成 Windows x64 安装版 `Grok-Desktop-1.3.0-Setup.exe` 和免安装版 `Grok-Desktop-1.3.0-Windows.exe`。

## 使用边界

2026-09-08 实测稳定版 Grok 1.0.13 尚未提供 ACP 图片输入；此版本 CLI 下会显示原因并保留草稿，不能将外壳的图片入口视为模型已支持看图。真实模型并发速度和账号限额未使用付费请求验证。

检查点只记录限定范围内的文本文件，未纳入内容会列出；它不是完整项目备份。运行 npm 脚本需要 Node.js。安装程序尚未配置发布者签名；自动更新桌面本身未在本次引入。
