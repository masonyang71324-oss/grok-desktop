# v1.7.4 审阅问题处理

基线：v1.7.3 / 9f12596。用户于 2026-10-04 授权根据 Claude 的独立报告修复问题。原则仍是稳定可靠、操作简单、保留现有功能。

## 本轮修复范围

- 模型原始 HTML 显示为源码，阻止样式、覆盖层、表单及应用 class 进入界面；保留 Markdown、代码高亮、公式和复制。
- Windows 系统程序使用绝对路径；项目 npm 的 Node 从绝对 PATH 目录解析。后台 Git 禁用 fsmonitor 和可选索引刷新。系统打开常见可执行文件前明确确认。正式包忽略开发网址覆盖。
- 检查点扫描上限只标记实际未覆盖的部分；不能把未知状态当删除。提供跨项目占用查看和显式批量清理，保护活跃记录。空间满额时由用户取消并清理，或明确选择本轮不创建检查点；恢复流程仍须先保存撤销记录。
- 损坏设置和队列保留原文件备份，备份失败时禁止覆盖；启动后显示恢复提醒。队列内容未变不重复写盘。草稿保持 300ms 防抖，增加 1 秒最长等待，并在写入 localStorage 后请求主进程刷盘。
- 文件树刷新保留同项目展开目录；准备期可停止且不再发送已取消的请求。中断条目明确说明继续队列会重新发送整条请求，提供查看改动入口。
- 持续文件变化也按最长等待刷新。更新错误保留真实原因并补英文文案。升级 Electron 44.5.1 和 http-cache-semantics；将已由 Vite 打包的渲染依赖移入开发依赖。

## 修复取舍与边界

- 不自动删除恢复记录；批量删除由用户选择并确认。自动淘汰可能损失未提交内容。
- 不把 gitignore 当唯一恢复清单，保留被忽略的本地配置文件及非 Git 项目支持；不笼统排除可能存放源码的 bin。
- 不全局改变可执行文件搜索环境；只修正本应用创建的系统进程。
- 准备期停止会禁止后续提交，但已经开始的会话加载/文档提取仍可能需要结束后才能完成收尾；不把该行为描述为立即终止所有 I/O。
- 本地刷盘改善意外退出时的草稿保留，不承诺突然断电零丢失。真实模型、麦克风、登录授权未纳入此次自动验证。
- 完整文件夹信任系统、IPC 路径授权登记、虚拟列表/历史格式改造、PTY utilityProcess/Fuses 迁移、主进程类型体系和 App 全面拆分属于后续架构工作。
- 检查点元数据索引、项目日志增量推送和文档归档后置；不通过删除空记录或缩减恢复覆盖来伪装性能收益。文件占用重试、真实 CLI 更新中断及 MCP/子代理退出范围仍需具体复现，未标记为已验证修复。
- 附件保留涉及旧会话引用，暂不自动清理；代码签名需要发布者证书，未在本轮伪称完成。开发变量限制保留打包产物测试入口。
