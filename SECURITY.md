# Reporting security issues

This desktop stores local settings and delegates account authentication to the official Grok Build CLI. Do not attach credentials, private prompts or complete user-data directories to public issues.

Report suspected vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/masonyang71324-oss/grok-desktop/security/advisories/new). Include the affected version, steps to reproduce and expected impact; remove credentials and private conversation content from attachments.

For ordinary reproducible bugs without sensitive information, use the [bug report template](https://github.com/masonyang71324-oss/grok-desktop/issues/new?template=bug_report.md).
